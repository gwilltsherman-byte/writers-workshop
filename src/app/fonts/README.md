# Font provenance

These WOFF2 assets are self-hosted through `next/font/local` in `src/app/layout.tsx`, with `font-display: swap`. They were copied from this clone’s Next.js Google Fonts cache generated by the original `next/font/google` download. The cache mapped them to the families and variants below. Exact `fonts.gstatic.com` binary download URLs were not retained; these family and CSS endpoints identify the source without claiming a recorded binary URL.

| Local file | Family | Style and weight | Source |
| --- | --- | --- | --- |
| `literata-latin.woff2` | Literata | Normal, variable 200–900, Latin subset | [Google Fonts](https://fonts.google.com/specimen/Literata) |
| `literata-italic-latin.woff2` | Literata | Italic, variable 200–900, Latin subset | [Google Fonts](https://fonts.google.com/specimen/Literata) |
| `courier-prime-latin.woff2` | Courier Prime | Normal 400, Latin subset | [Google Fonts](https://fonts.google.com/specimen/Courier+Prime) |
| `courier-prime-bold-latin.woff2` | Courier Prime | Normal 700, Latin subset | [Google Fonts](https://fonts.google.com/specimen/Courier+Prime) |

Google Fonts CSS requests for the corresponding variants:

- [Literata normal and italic, 200–900](https://fonts.googleapis.com/css2?family=Literata:ital,wght@0,200..900;1,200..900&display=swap)
- [Courier Prime normal, 400 and 700](https://fonts.googleapis.com/css2?family=Courier+Prime:wght@400;700&display=swap)

CSS responses may vary by user agent or upstream revision; these are source references, not a promise of byte-identical future downloads.

Both families use SIL Open Font License 1.1. Complete licenses are distributed alongside the fonts:
