# Run Writers' Workshop on Mac and iPhone

## Mac

Use Node.js 20 as specified in `.nvmrc`, with npm, and PostgreSQL.
For this private repository, authenticate to GitHub when cloning, or download
the ZIP from Code in the repository and extract it.

```sh
git clone https://github.com/gwilltsherman-byte/writers-workshop-clean.git
cd writers-workshop-clean
cp .env.example .env
```

Create a PostgreSQL database named `writers_workshop`. In `.env`, set
`DATABASE_URL` to its connection string and `AUTH_SECRET` to a random value
generated by `openssl rand -base64 32`. A hosted PostgreSQL database also works;
use the credentials supplied by that database provider.

Then run:

```sh
npm ci
npm run migrate
npm run dev
```

Open `http://localhost:3000`. Keep Terminal open; Control-C stops the app.
The development server serves the website and its Socket.IO/Yjs live features.
Without SMTP in development, the signup flow shows verification codes for testing.

## iPhone over your home Wi-Fi

Keep the Mac awake and connect both devices to the same Wi-Fi. Find the Mac's
IP address in System Settings, Wi-Fi, Details, TCP/IP. Stop the app and run:

```sh
APP_BASE_URL=http://MAC_IP:3000 npm run dev
```

Replace `MAC_IP` with that address, then open `http://MAC_IP:3000` in Safari.
Setting the base URL this way lets the live server accept the phone's origin.
Leave `NEXT_PUBLIC_REALTIME_URL` empty for this single-server setup.
Allow the server through the Mac firewall if needed. Use Share, Add to Home
Screen for a shortcut. The Mac must remain on and the server must remain running.

## GitHub hosting

GitHub Pages serves static files. This app needs a running Node server, API
routes, PostgreSQL and WebSockets; Pages cannot host the complete app.

For a GitHub development environment, create a Codespace from Code, Codespaces.
Configure a reachable database, run the setup commands above, and open the
forwarded port 3000. Set `APP_BASE_URL` to that forwarded HTTPS address before
restarting the app. Keep the forwarded port private and sign in with your
GitHub account on the iPhone to access it. A Codespace runs only while active
and is a development option rather than permanent hosting.
